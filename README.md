# Build with Arduino UNO Q: Hackout Edition

Choose one of the two tracks below. Each track has its own App Lab application, starter code, and hardware reference. The kits for both the tracks are supplied **preassembled**.

| Track   | Build                                                             | Start here                         |
| ------- | ----------------------------------------------------------------- | ---------------------------------- |
| Robocar | A robot that detects a ball, moves toward it, and attempts a goal | [Robocar guide](robocar/README.md) |
| Arcade  | A game played with Modulino controls on the console's TFT         | [Arcade guide](arcade/README.md)   |

## Project rubrics

Each track totals **100 points**. Criterion weight ranges from **0–4**: absent, partial, basic, reliable, or consistently demonstrated.

### Robocar rubric

| Criterion                       |  Weight | What to demonstrate                                                                              |
| ------------------------------- | ------: | ------------------------------------------------------------------------------------------------ |
| Ball detection                  |      25 | Finds the ball across the agreed conditions and autonomously acts on it.                         |
| Actions driven by perception    |      25 | Fresh observations control short steering and approach movements.                                |
| Goal-directed behavior          |      20 | Aligns the ball with the goal and scores under the challenge conditions.                         |
| Reliability and safe recovery   |      20 | Stops on lost ball, stale video, or errors; restarts predictably.                                |
| Explanation and reproducibility |      10 | Source, launch instructions, calibration, results, and credits let someone else repeat the demo. |
| **Total**                       | **100** |                                                                                                  |

### Arcade rubric

| Criterion                       |  Weight | What to demonstrate                                                                                |
| ------------------------------- | ------: | -------------------------------------------------------------------------------------------------- |
| Playability and game loop       |      30 | A new player understands the objective, completes a round, and restarts.                           |
| UNO Q and control integration   |      25 | The game runs on UNO Q with visible TFT gameplay and responsive, calibrated controls.              |
| Originality and game design     |      20 | A distinct mechanic or thoughtful variation, purposeful controls, and a sensible challenge curve.  |
| Reliability and performance     |      15 | Repeated play stays responsive, without stuck inputs; unavailable controls are handled clearly.    |
| Explanation and reproducibility |      10 | Source, launch instructions, control map, calibration, and credits let someone else play the game. |
| **Total**                       | **100** |                                                                                                    |
